> **2026년 제25회 청소년상담사 2급 국가전문자격시험 완벽 대비 실전 CBT 웹앱**  
> 10개 회차(제1회~제10회) × 회차당 150문항 = **총 1,500문제 풀패키지**  
> 1교시(필수 4과목 100문항) + 2교시(선택 2과목 [가족상담 + 집단상담] 50문항)

## 🌟 핵심 기능 및 특징

1. **10회 풀세트 실전 모의고사 (총 1,500문항)**
   - **제1회** 적중 모의고사 (150제)
   - **제2회** 고난도 실전 (150제)
   - **제3회** 핵심 기출변형 (150제)
   - **제4회** 심층 빈출마스터 (150제)
   - **제5회** 킬러문항 극복 (150제)
   - **제6회** 수석합격 예측 (150제)
   - **제7회** 전범위 총정리 (150제)
   - **제8회** 고난도 사례형 (150제)
   - **제9회** 파이널 실전 (150제)
   - **제10회** 최종 만점대비 (150제)

2. **과목 구성 (과목당 25문항, 회차당 150문항)**
   - **[1교시 필수 4과목 / 100문항 / 100분]**
     - ① 제1과목: 청소년 상담의 이론과 실제 (25문항)
     - ② 제2과목: 상담연구방법론의 기초 (25문항)
     - ③ 제3과목: 심리측정 및 평가의 활용 (25문항)
     - ④ 제4과목: 청소년 이상심리 (25문항)
   - **[2교시 선택 2과목 / 50문항 / 50분]**
     - ⑤ 제5과목: 가족상담 (선택1, 25문항)
     - ⑥ 제6과목: 집단상담 (선택2, 25문항)

3. **자동 채점 및 합격/과락 판정 시스템**
   - **과목별 취득 점수 자동 산출** (100점 만점 환산)
   - **과락 판정 기준 적용**: 과목당 40점 미만 시 불합격 처리
   - **합격 판정 기준 적용**: 전 과목 과락 없이 전체 평균 60점 이상 시 최종 합격(PASS)
   - **오답노트 모아보기 & 북마크(⭐) 기능** 제공

4. **태블릿 & 모바일 최적화 UI**
   - **다이내믹 글자 크기 조절기** (`A-`, `100%`, `125%`, `150%`, `175%`, `A+`)
   - **태블릿/데스크탑 분할 뷰** (좌측 문제지 + 우측 실시간 OMR 패널)
   - **모바일 원터치 슬라이드업 OMR 드로어**
   - **터치 스와이프 제스처** (좌우 넘기기)
   - **Web Audio 햅틱 사운드 피드백** (정답음, 오답음, 클릭음)

5. **3가지 학습 모드 지원**
   - 📝 **실전 5지선다 CBT 모의고사 모드**
   - 📖 **150제 일목요연 요약표 & 자가테스트 모드**
   - 🗂️ **3D 1초 킬러 플래시카드 모드** (자동 스캔 지원)
